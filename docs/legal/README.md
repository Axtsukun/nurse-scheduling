# 看護師勤務に関する法令・基準の調査（docs/legal）

調査日: 2026-10-30 ／ 状態: **調査のみ。実装には未反映。**

## このフォルダの使い方
| ファイル | 内容 | 読む場面 |
|---|---|---|
| `constraints.yaml` | 制約の一覧（機械可読）。ID・区分・確度・モデル上の対応・実装状況 | 制約を追加・修正する前に、まずここを引く |
| `01_law.md` | A: 法令の義務（労基法・育児介護休業法・安衛則）の詳細 | ハード制約の根拠を確認するとき |
| `02_reimbursement.md` | B: 診療報酬の施設基準・C: 医療法の人員標準 | 72時間ルール・夜勤人数・看護配置を触るとき |
| `03_guidelines.md` | D: 努力義務・日本看護協会ガイドライン | ソフト制約／病院ごとのハード化を設計するとき |
| `04_model_mapping.md` | 現行モデルとの対応表と未実装の一覧 | 実装計画を立てるとき |
| `05_sources_and_gaps.md` | 情報源、未確認事項、アクセスできなかったサイト | 確度を上げる調査をするとき |

## 区分（constraints.yaml の `class`）
- **A 法令の義務**: 違反に罰則。勤務表の絶対条件。
- **B 診療報酬の施設基準**: 届出要件。満たさないと減算・届出取り下げ。法令ではないが事実上のハード制約。
- **C 医療法の人員標準**: 病棟・病院単位の人員。日々の勤務表より上位の階層。
- **D 努力義務・ガイドライン**: 強制力なし。ソフト制約、または病院ごとにハード化。

## 確度（`confidence`）
- **high(◎)**: 検索結果に条文・通知の内容があり、複数の資料で確認できた。
- **medium(○)**: 検索結果で確認できたが、民間サイト等の二次資料の要約のみ。
- **low(△)**: 検索結果に出ず、一般知識で補った。**原典で確認するまで実装の根拠にしない。**

## 重要な注意
- 一次資料（厚生労働省・e-Gov法令検索・日本看護協会）は調査時にアクセスできなかった（`05_sources_and_gaps.md`）。
- 診療報酬の基準は改定ごとに変わる。**2026年度改定後の施設基準は未確認。**
- 実装に反映する前に、必ず原典（条文・通知）で該当箇所を確認すること。
